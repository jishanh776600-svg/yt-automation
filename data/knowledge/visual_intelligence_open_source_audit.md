## Licensing & Compliance Summary
1. **Zero GPL/AGPL Contamination:** The internetarchive AGPL package is strictly rejected from Python imports. All Internet Archive searches are conducted via its public JSON web endpoints.
2. **Commercial Use Guarantee:** All selected libraries (scenedetect, Pillow, NumPy, PyAV, yt-dlp, MediaWiki API) carry permissive open-source licenses (BSD, MIT, Apache 2.0, Unlicense) verified for commercial deployment.
3. **Deterministic Testing Invariant:** Every external API adapter (Wikimedia, Archive, Editorial, Pexels) implements a capability-gated fallback returning deterministic structured mocks when llow_network_read=False or TEST_MODE=True.
